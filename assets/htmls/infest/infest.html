1인칭 3D 생존 / 슈팅 / 멀티 좀비 FPS

5인 개발 (기획 1 / 개발 4)

📸 개발 결과

🛠 사용 기술

Unity Photon Fusion2 Analytics

⚙ 핵심 구현

  • 1. 몬스터 (프레임워크, 기능)
  • 2. 플레이어 (프레임워크, 기능)
  • 3. 네트워크 (매칭, 플레이)

🧠 트러블 슈팅

NavMesh와 NetworkTransform이 서로 네트워크 객체의 transform을 제어하려다 충돌해 몬스터 스폰 위치에 큰 오차 발생 → 스폰되는 순간에 NetworkTransform을 비활성화 상태로 두어 충돌 해결
Time.deltaTime 기반 물리 연산이 네트워크 물리 연산의 특수성과 맞지 않아 호스트 간 이동 속도 오차 발생 → Runner.DeltaTime 기반으로 전환하여 네트워크 물리 연산에 대응해 이동 속도 오차 해결

🚀 최적화

  • Light Baking (Batch 30,000 → 10,000)
  • Occlusion Culling (Batch 10,000 → 1,000)
  • Network Packet Size Optimization
