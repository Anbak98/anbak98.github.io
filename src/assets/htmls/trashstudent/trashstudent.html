  • 단일 책임 원칙 기반 리팩토링으로 협업 생산성 향상
  • 개방 폐쇄 원칙과 의존성 역전 원칙 기반 리팩토링으로 소프트웨어 생명 연장
  • class diagram을 활용한 게임 전체 구조 문서화와 실 구현으로 유지보수성 확보
  • Unity Project Auditor를 활용한 프로젝트 점검으로 안정성 증가
  • 무한 스크롤과 오브젝트 풀링으로 성능 최적화
  • 다양한 모바일 해상도에 대응 가능한 반응형 UI 작업
  • 핸드폰 진동 기능

🧠 트러블 슈팅

휴대폰 진동 기능을 추가했을 때 안드로이드 빌드에서 원인 모를 오류가 발생, cmd로 모바일 빌드 로그를 가져와 에러 로그를 확인해 권한 문제임을 확인하고 안드로이드 스튜디오로 확인하니 실제 진동 권한이 빠져있음을 확인. Handheld.Vibrate 함수가 최소 하나 있어야 권한이 추가됨을 알고 해결.
